# Evidencias de My Running

En esta carpeta vamos a guardar las evidencias que utilizamos para desarrollar y probar My Running.

## Entrenamientos reales

Tomamos como referencia siete entrenamientos registrados en la aplicación Zepp, con diferentes distancias, tiempos y ritmos.

Estos registros nos permiten trabajar con datos reales y comprobar cómo funciona el ranking de mejores ritmos.

## Pruebas del programa

También incorporaremos capturas de la terminal de Python para mostrar el funcionamiento de las estructuras de datos y los resultados de las pruebas realizadas.

## Privacidad

Antes de publicar las capturas de los entrenamientos, ocultaremos los nombres y los mapas GPS que puedan mostrar ubicaciones personales.

Los datos deportivos originales se conservarán sin modificaciones.
